# SISTEMA BANCÁRIO SIMPLES
Criado a partir da Linguagem C, esse sistema tem como finalidade fazer a famosa troca de cédulas de notas com valores altos. Para o seu uso, o programa irá pedir o valor em reais ao usuário e depois por qual nota ele quer trocar e ao final informar o troco. 

# COMPILADOR E FERRAMENTAS
1 Linguagem C
2 VsCode

# COMO RODAR O PROJETO?
No BASH:
    Clonar o repositório abaixo
    git clone https://github.com/iumoreira/SIMULADOR-BANCARIO-SIMPLES.git

Entre na pasta cd Repositorios

No BASH:
    cd SIMULADOR-BANCARIO-SIMPLES
    gcc main.c -o programa
    ./programa
No VsCODE
    Copiar e colar o código
